# CLAUDE.md  (터미널 AI가 Claude Code일 때 저장소 루트에 둔다)

이 프로젝트의 작업 지침은 AGENTS.md에 있다. 먼저 AGENTS.md, PROBLEM.md, GIT.md를 읽고 그대로 따른다. 스킬은 `.claude/skills/`에 있고 `/이름`으로 호출한다.

## Claude Code 추가 규칙
- 조사, 테스트 작성, 코드 리뷰처럼 서로 독립적인 작업은 서브에이전트에 나눠 맡기고, 결과는 메인 세션에서 통합한다.
- 요구사항에 없는 범용 기능(과한 추상화, 미래 대비 옵션, 과도한 검증 장치)은 넣지 말고 제안만 한다.
- 비용을 의식한다. 같은 파일을 반복해서 통째로 읽거나 전체를 재작성하지 않는다.
- 단계가 끝나면 묻지 말고 `/git-commit` 절차로 커밋한다. 커밋 메시지 작성처럼 단순한 일에 effort를 높이지 않는다.
